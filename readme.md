## 📖 نبذة عن المشروع (Overview)

مشروع **دليل أرباحي المعتمد (Earn Directory)** هو دليل ويب تفاعلي مفتوح المصدر مصمم لمساعدة المبتدئين والمحترفين في الوصول السريع إلى منصات الربح الموثوقة عبر الإنترنت دون الوقوع في فخ المواقع الوهمية[cite: 13].

يعرض الدليل بيانات تفصيلية لكل موقع تشمل: **معدل الربح اليومي والشهري المتوقع، الحد الأدنى للسحب، الوقت اليومي المطلوب، عمر الموقع منذ التأسيس، طرق الدفع المتاحة، روابط إثباتات السحب المباشرة عبر تيليجرام، وروابط الشروحات المصورة على يوتيوب[cite: 1, 2, 13].**

## ✨ المميزات الرئيسية والتقنية (Key Features)

* 📊 **لوحة إحصائيات ذكية (Live Dashboard):** حساب تلقائي وفوري لإجمالي عدد المنصات المضافة، إجمالي الربح اليومي والشهري المتوقع بالدولار، وتحديد المنصة الأعلى ربحاً[cite: 2, 13].
* 🔍 **محرك بحث وفلترة فوري (Smart Search & Filtering):**
  * فلترة ديناميكية حسب **الفئة** (صنابير، مهام، إعلانات PTC، ألعاب، أفيليت، محافظ) وحسب **عملة الربح** (`USD`, `RUB`, `EGP`, `USDT`, `BTC`, `TRX`, `DOGE` وغيرها)[cite: 1, 2, 13].
  * بحث نصي فوري مع تظليل الكلمات المطابقة (Search Highlighting)، وميزة البحث الذكي الاحتياطي عبر جوجل ويوتيوب في حال عدم توفر الموقع في القائمة[cite: 2, 13].
* 🎨 **4 مظاهر للعرض (4 Custom Themes):** دعم الوضع التلقائي (Auto)، الوضع الليلي (Dark Mode)، الوضع الفاتح (Light Mode)، و**وضع راحة العين (Eye Comfort Mode)** المصمم خصيصاً للقراءة الطويلة[cite: 2, 13].
* 🌍 **ثنائي اللغة بالكامل (Bilingual AR/EN):** تبديل فوري بين اللغتين العربية (`RTL`) والإنجليزية (`LTR`) مع حفظ تفضيلات الزائر في المتصفح (`localStorage`)[cite: 2, 13].
* ⚡ **أداء فائق وتحسين متقدم للسيو (Performance & SEO Optimized):**
  * استبدال مكتبات الخطوط الثقيلة بنظام **Inline SVG Sprites** مدمج لتحقيق سرعة تحميل قصوى ومنع أي إزاحة في التصميم (`Zero CLS`)[cite: 2, 13].
  * تقنية **Lazy DOM Rendering** لعرض أول 10 بطاقات في كل قسم وتحميل الباقي عند الطلب لتقليل حجم الـ DOM[cite: 2, 13].
  * دعم كامل لبيانات **Schema.org (JSON-LD)**، وملفات `sitemap.xml` و `robots.txt` ووسوم OpenGraph[cite: 2, 5, 6, 13].
* 📌 **تتبع الزيارات وحفظ التقدم:** تلوين المواقع التي تمت زيارتها تلقائياً حتى يسهل على المستخدم معرفة المنصات التي سجل بها مسبقاً[cite: 2, 13].
* 💬 **ودجت دعم فني تفاعلي:** زر محادثة ذكي يتيح للزوار إرسال استفساراتهم مباشرة عبر **تيليجرام** أو **واتساب**[cite: 2, 13].

## 🛠️ طريقة التعديل وإضافة مواقع جديدة (How to Customize)

المشروع مصمم بفصل كامل بين البيانات وواجهة العرض[cite: 13]. لإضافة موقع جديد، لا تحتاج لتعديل كود `index.html` إطلاقاً؛ فقط افتح ملف **`sites-data.js`** وأضف كائناً جديداً داخل القسم المناسب بهذا الشكل[cite: 1, 13]:

</div>

```javascript
{
  id: 999,
  name: "اسم الموقع",
  url: "[https://example.com/?ref=YOUR_ID](https://example.com/?ref=YOUR_ID)",
  daily: 0.5,               // الربح اليومي المتوقع بالدولار
  currency: "USD",          // عملة الربح (USD, RUB, USDT, BTC...)
  category: "tasks",        // التصنيف (tasks, ptc, faucet, games, affiliate, wallet)
  startDate: "2023-01-15",  // تاريخ تأسيس الموقع (لحساب العمر تلقائياً)
  timeMinutes: 15,          // الوقت اليومي المطلوب بالدقائق
  description: "وصف مختصر لطريقة العمل والربح من الموقع.",
  minWithdraw: "$0.10",     // الحد الأدنى للسحب
  paymentLinks: ["faucetpay", "binance", "cwallet"], // طرق السحب من ملف withdrawal-methods.js
  proof: "[https://t.me/MajdEarn](https://t.me/MajdEarn)" // رابط إثبات الدفع
}
```
