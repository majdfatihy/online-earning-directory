## 📖 نبذة عن المشروع (Overview)

مشروع **Earn Directory (دليل أرباحي المعتمد)** هو دليل ويب تفاعلي مفتوح المصدر مصمم لمساعدة المبتدئين والمحترفين في الوصول السريع إلى منصات الربح الموثوقة عبر الإنترنت دون الوقوع في فخ المواقع الوهمية. 

يعرض الدليل بيانات تفصيلية لكل موقع تشمل: **معدل الربح اليومي والشهري المتوقع، الحد الأدنى للسحب، الوقت اليومي المطلوب، عمر الموقع منذ التأسيس، طرق الدفع المتاحة، روابط إثباتات السحب المباشرة عبر تيليجرام، وروابط الشروحات المصورة على يوتيوب.**

## ✨ المميزات الرئيسية والتقنية (Key Features)

* 📊 **لوحة إحصائيات ذكية (Live Dashboard):** حساب تلقائي وفوري لإجمالي عدد المنصات المضافة، إجمالي الربح اليومي والشهري المتوقع بالدولار، وتحديد المنصة الأعلى ربحاً.
* 🔍 **محرك بحث وفلترة فوري (Smart Search & Filtering):**
  * فلترة ديناميكية حسب **الفئة** (صنابير، مهام، إعلانات PTC، ألعاب، أفيليت، محافظ) وحسب **عملة الربح** (`USD`, `RUB`, `EGP`, `USDT`, `BTC`, `TRX`, `DOGE`, إلخ).
  * بحث نصي فوري مع تظليل الكلمات المطابقة (Search Highlighting)، وميزة البحث الذكي الاحتياطي عبر Google و YouTube في حال عدم توفر الموقع في القائمة.
* 🎨 **4 مظاهر للعرض (4 Custom Themes):** دعم الوضع التلقائي (Auto)، الوضع الليلي (Dark Mode)، الوضع الفاتح (Light Mode)، و**وضع راحة العين (Eye Comfort Mode)** المصمم خصيصاً للقراءة الطويلة.
* 🌍 **ثنائي اللغة بالكامل (Bilingual AR/EN):** تبديل فوري بين اللغتين العربية (`RTL`) والإنجليزية (`LTR`) مع حفظ تفضيلات الزائر في المتصفح (`localStorage`).
* ⚡ **أداء فائق وتحسين متقدم للسيو (Performance & SEO Optimized):**
  * استبدال مكتبات الخطوط الثقيلة بنظام **Inline SVG Sprites** مدمج لتحقيق سرعة تحميل قصوى ومنع أي إزاحة في التصميم (`Zero CLS`).
  * تقنية **Lazy DOM Rendering** لعرض أول 10 بطاقات في كل قسم وتحميل الباقي عند الطلب لتقليل حجم الـ DOM.
  * دعم كامل لبيانات **Schema.org (JSON-LD)**، وملفات `sitemap.xml` و `robots.txt` ووسوم OpenGraph.
* 📌 **تتبع الزيارات وحفظ التقدم:** تلوين المواقع التي تمت زيارتها تلقائياً حتى يسهل على المستخدم معرفة المنصات التي سجل بها مسبقاً.
* 💬 **ودجت دعم فني تفاعلي:** زر محادثة ذكي يتيح للزوار إرسال استفساراتهم مباشرة عبر **تيليجرام** أو **واتساب**.

## 📁 هيكلة ملفات المشروع (Project Structure)

```text
online-earning-directory/
├── index.html              # الصفحة الرئيسية التفاعلية للدليل (SPA-like architecture)
├── sites-data.js           # قاعدة بيانات جميع المواقع والأقسام والإحصائيات (JSON/JS Array)
├── withdrawal-methods.js   # قائمة طرق الدفع والمحافظ وروابطها المعتمدة
├── adsterra.js             # وحدة مستقلة لإدارة الإعلانات المتجاوبة (Lazy-loaded iframes)
├── privacy.html            # صفحة سياسة الخصوصية وإشعار الكوكيز
├── terms.html              # صفحة شروط الاستخدام والملكية الفكرية
├── disclaimer.html         # صفحة إخلاء المسؤولية المالية والقانونية
├── sitemap.xml             # خريطة الموقع لمحركات البحث (Google Search Console)
├── robots.txt              # ملف توجيه عناكب البحث
└── README.md               # ملف توثيق المشروع
```

## 🛠️ طريقة التعديل وإضافة مواقع جديدة (How to Customize)

المشروع مصمم بفصل كامل بين البيانات (`Data`) وواجهة العرض (`UI`). لإضافة موقع جديد، لا تحتاج لتعديل كود `index.html` إطلاقاً؛ فقط افتح ملف **`sites-data.js`** وأضف كائن جديد داخل القسم المناسب بهذا الشكل:

```javascript
{
  id: 999,
  name: "اسم الموقع",
  url: "https://example.com/?ref=YOUR_ID",
  daily: 0.5,               // الربح اليومي المتوقع بالدولار
  currency: "USD",          // عملة الربح (USD, RUB, USDT, BTC...)
  category: "tasks",        // التصنيف (tasks, ptc, faucet, games, affiliate, wallet)
  startDate: "2023-01-15",  // تاريخ تأسيس الموقع (لحساب العمر تلقائياً)
  timeMinutes: 15,          // الوقت اليومي المطلوب بالدقائق
  description: "وصف مختصر لطريقة العمل والربح من الموقع.",
  minWithdraw: "$0.10",     // الحد الأدنى للسحب
  paymentLinks: ["faucetpay", "binance", "cwallet"], // طرق السحب من ملف withdrawal-methods.js
  proof: "https://t.me/MajdEarn" // رابط إثبات الدفع
}
```

## 🚀 التشغيل المحلي (Run Locally)

المشروع مبني بـ **Vanilla JavaScript / HTML5 / CSS3** بدون أي اعتماديات معقدة (Zero Dependencies):

1. قم باستنساخ المستودع (Clone):
   ```bash
   git clone https://github.com/majdfatihy/online-earning-directory.git
   ```
2. ادخل إلى مجلد المشروع:
   ```bash
   cd online-earning-directory
   ```
3. افتح ملف `index.html` مباشرة في أي متصفح حديث، أو استخدم إضافة `Live Server` في VS Code.
